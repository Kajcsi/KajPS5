# Security policy

KajPS5 reads untrusted binary data. Treat every game file, firmware file, and
trace as potentially hostile.

Use GitHub private vulnerability reporting for a defect that could execute
host code, read files outside the selected data directory, or expose private
data. Do not report those problems in a public issue.

Include the affected commit, host operating system, expected result, and the
smallest test case you can legally share. Never include game data, keys, or
proprietary system files.
