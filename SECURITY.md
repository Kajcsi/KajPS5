# Security policy

KajPS5 handles untrusted binary data. Treat each game file, firmware file, and
trace as untrusted input.

Do not open a public issue for a security defect that can execute host code,
read files outside the selected data directory, or expose private data. Use
GitHub private vulnerability reporting for this repository.

Include the affected commit, host operating system, a small test case when it
is legal to share, and the expected result. Do not include game data, keys, or
proprietary system files.
